Day-5 (Path Parameters)

1. What is a Path Parameter?
A Path Parameter is a dynamic value that is passed inside the URL path. It is mainly used to identify a specific resource such as a student, product, user, or order.
Example-
/student/10
What is the use of Path Parameter?
Path Parameters are mainly used to retrieve a specific resource.
Examples
/student/10
/product/100
/user/25
/order/500
Path Parameter vs Query Parameter?
Example
Path Parameter- /student/10
Query Parameter- /students?course=AI

Why does FastAPI return 422 Validation Error?
FastAPI returns 422 Unprocessable Entity when the client sends invalid data that does not match the expected data type or validation rules defined in the application.
Key Points Path Parameters
Path Parameters are part of the URL.
Used to access a specific resource.
FastAPI automatically validates data types.
Invalid values return 422 Validation Error.
Path Parameters are commonly used with GET, PUT, DELETE APIs.
