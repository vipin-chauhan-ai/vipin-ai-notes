Day 7 - HTTPException

1. What is HTTPException?

Answer

HTTPException is used to return custom HTTP error responses from a FastAPI application. It allows us to send an appropriate status code and error message to the client.

2. Why do we use HTTPException?

Answer

We use HTTPException to handle errors professionally and return meaningful HTTP status codes instead of returning normal JSON responses.

3. Syntax of HTTPException
from fastapi import HTTPException
raise HTTPException(
status_code=404,
detail="Student Not Found"

)

4. Why do we use raise instead of return?

Answer

return sends normal data and usually returns 200 OK.
raise HTTPException immediately stops the execution and returns the specified error status code.
5. What is the difference between return and raise?

Difference between return and raise

return raise
Returns data. Raises an exception.
Normal execution continues. Execution stops immediately.
Usually returns 200 OK. Returns a custom HTTP status code (e.g. 404, 401, 403, 500).
6. What happens if we use return instead of raise?

Example

return {

"message": "Student Not Found"

}

Output

200 OK

This is not a professional API because the client thinks the request was successful.

7. Which status code should be used if a resource is not found?

Answer

404 Not Found

Example

/student/100

If Student ID 100 does not exist, return 404 Not Found.

8. Difference between 404 and 422?

Difference between 404 Not Found and 422 Validation Error

404 Not Found 422 Validation Error
Resource does not exist. Invalid request data.
Student not found. Wrong data type or validation failure.
