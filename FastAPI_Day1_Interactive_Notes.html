🚀 FastAPI Day 1 - Introduction & First API

What is FastAPI?

FastAPI is a modern Python web framework used for building fast and high-performance APIs. It is based on Python type hints and supports asynchronous programming.

Why FastAPI?

Very Fast

Easy to Learn

Automatic Swagger Documentation

High Performance

Async Support

Data Validation

Type Hint Support

Why is FastAPI faster than Flask?

Because it uses ASGI, supports asynchronous programming, and is built on Starlette.

What is Uvicorn?

Uvicorn is an ASGI server used to run FastAPI applications.

What is Swagger UI?

Swagger UI is an automatically generated API documentation interface available at /docs.
