Day 8 - PUT Method

1. What is the PUT Method?

Answer

PUT method is used to update an existing resource on the server.

PUT method ka use server par existing data ko update karne ke liye hota hai.

2. Why do we use the PUT Method?

Answer

We use the PUT method when an existing record needs to be modified or updated.

Example:

Update Student

Update Employee

Update Product

Update User Profile

3. Syntax of PUT Method
@app.put("/student/{id}")

def update_student(id: int, student: Student):

return student

4. Difference between POST and PUT
POST PUT
Creates a new resource. Updates an existing resource.
Used for Insert. Used for Update.
Example: Add Student. Example: Update Student.
5. Why do we use Path Parameter with PUT?

Answer

The Path Parameter identifies which resource should be updated.

Example

PUT /student/1

Here, 1 is the Student ID to update.

6. What happens if the resource does not exist?

Answer

Return:

404 Not Found

Example

raise HTTPException(

status_code=404,

detail="Student Not Found"

)

7. What is the Request Body in PUT?

Answer

The Request Body contains the updated data sent by the client.

Example

{

"name":"Vipin",

"age":31,

"course":"AI Engineer"

}

8. Why do we use Pydantic in PUT?

Answer

Pydantic validates the incoming data before updating the resource.

If invalid data is received, FastAPI automatically returns:

422 Validation Error

9. Why do we use model_dump()?

Answer

model_dump() converts the Pydantic model into a Python dictionary.

Example

students[id] = student.model_dump()
