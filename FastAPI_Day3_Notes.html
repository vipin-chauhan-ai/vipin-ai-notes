What is HTTP?
HTTP (HyperText Transfer Protocol) is used for communication between the browser and the server.
What is Request?
A Request is sent by the client to the server.
What is Response?
A Response is returned by the server to the client.
Browser → Server Flow
Browser → HTTP Request → Uvicorn → FastAPI → Route → Function → JSON Response → Browser
GET Method
GET is used to fetch data from the server.

Code Example

from fastapi import FastAPI

app = FastAPI()

@app.get("/student")
def student():
    return {"name":"Vipin"}

@app.get("/company")
def company():
    return {"company":"OpenAI"}

Interview Questions

URL vs Route
URL: Browser address
Route: Endpoint defined in FastAPI.
Request vs Response
Request: Client → Server
Response: Server → Client
